# Space Uganda Website App

This is the Next.js application for `space.org.ug`.

Quick start:

```bash
npm install
cp .env.example .env
docker compose up -d
npm run db:push
npm run db:seed
npm run dev
```

Useful routes:

- Public site: `/`
- WSW Uganda 2026: `/wsw-2026`
- Public intake form: `/join`
- Admin portal: `/admin`

Use the root `README.md` for the full project overview.
